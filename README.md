# 🎌 Anime Index

A full-stack anime discovery app built with React and TypeScript. Search any anime, explore details, and save your favorites — backed by Firebase and the Jikan API.

## ✨ Features

- 🔍 **Anime search** — live search powered by the Jikan API with retry logic and smooth loading states
- 💾 **Personal list** — save and manage your favorite anime, persisted via Firebase Firestore
- 🔐 **Authentication** — sign up and sign in with Firebase Auth
- 🎬 **Anime detail page** — trailer, synopsis, score, rank, studio, and more
- 🎞️ **Entrance animations** — staggered card reveals and page transitions via Framer Motion
- 📱 **Responsive** — mobile-first layout with adaptive navbar

## 🛠️ Stack

| Tool            | Use                        |
| --------------- | -------------------------- |
| React 18        | UI components              |
| TypeScript      | Type safety                |
| Tailwind CSS 3  | Utility-first styling      |
| Firebase        | Auth & Firestore database  |
| Framer Motion   | Animations and transitions |
| Jikan API       | Anime data source          |
| React Router v6 | Client-side routing        |

## 🚀 Run locally

```bash
git clone https://github.com/Xaida02/anime-index-typescript.git
cd anime-index-typescript
npm install
```
